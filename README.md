# AI-Powered Store Surveillance System for People Counting and Abnormal Behavior Detection

## Project Overview
This project aims to develop an AI-powered surveillance system for retail stores, focusing on:
- Real-time people counting
- Detection of abnormal behaviors (e.g., theft, loitering, crowding)

## Features
- Video stream processing
- Deep learning models for detection
- Data logging and analytics
- Modular and extensible codebase

## Project Structure
- `src/` - Source code for models and processing
- `data/` - Sample datasets and data storage
- `notebooks/` - Jupyter notebooks for experiments
- `tests/` - Unit and integration tests

## Setup Instructions
1. Clone the repository
2. Create a Python virtual environment
3. Install dependencies (see `requirements.txt`)
4. Run sample scripts in `src/` or notebooks in `notebooks/`

## Usage Example
```bash
python src/people_counter.py --input data/sample_video.mp4
```
